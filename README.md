# Inflatable Pool Factory

Multilingual (37 languages) marketing and B2B platform for **Inflatable Pool Factory** — premium drop stitch inflatable swimming pools by the Inflatable Pool Team at Qingdao Vatrad Group Co., Ltd. (Qingdao, Shandong, China).

- **Site:** https://inflatablepoolfactory.com — ~663 static pages, 187 sitemap URLs (7 sitemaps)
- **Stack:** Astro 7 (Vite 8 / Rolldown, `output: 'static'`) · Tailwind CSS 4 · TypeScript · MDX · Cloudflare Pages + 5 Workers · D1 · R2 · Vectorize
- **Legal identity:** Inflatable Pool Team at Qingdao Vatrad Group · `info@inflatablepoolfactory.com`

## Quick Start

```bash
npm install        # Node >= 22.12.0
npm run dev        # dev server at localhost:4321
npm run build      # full pipeline -> ./dist (663 pages + validate-dist gate)
npm run preview    # preview the production build
npm run check      # astro check + ESLint + Prettier + i18n + assets + AI content gates
npm run quality    # check + 7 test suites (103 tests) + build + route/link audits
```

Daily deploy: push to `main` — CI builds, runs all gates, uploads `public/` assets to R2 (auto-prune) and deploys `dist/` to Cloudflare Pages.

## Quality Gates

Every change passes:

1. `npm run check` — astro check (0 errors), ESLint, Prettier, translation alignment, asset ledger, AI content review
2. 7 test suites — `test:assets` / `test:content` / `test:ai` / `test:pdf` / `test:oem` / `test:prices` / `test:sample` (103 tests)
3. `npm run build` — 663 pages, `validate-dist` PASS
4. `npm run check:links` — 0 broken internal links; `npm run check:routes` — route matrix 0 errors
5. Zero mojibake (`\uFFFD`) anywhere in `src/` and `dist/`

## Key Rules

- New legacy URLs go into `LEGACY_REDIRECTS` in `astro.config.ts` — never as `Astro.redirect()` page files.
- Large generated JSON stays in `src/i18n/generated/` (gitignored) — never in `public/` (Cloudflare Pages 25 MiB limit).
- Product images are WebP (1600px, q82); `src/data/site/image-dimensions.json` is regenerated by every build.
- AI-assisted content requires `aiGenerated: true` + `aiReview` records in `src/data/site/ai-content-reviews.yaml` (enforced by `check:ai-content.mjs`).
- New `public/images/**` files require an `asset-ledger.yaml` entry (enforced by `check-asset-ledger.mjs`).
- English canonical lives at the root; other locales under `/<lang>/`. EN-only routes are listed in `src/i18n/root-only.ts`.
